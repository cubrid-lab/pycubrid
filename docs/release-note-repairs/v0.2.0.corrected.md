## v0.2.0 — Wire Protocol

### Added
- Wire protocol `PacketWriter` and `PacketReader` for CAS binary frame serialization/deserialization
- 18 CAS protocol packet classes (ClientInfoExchange, OpenDatabase, Prepare, Execute, Fetch, Commit, Rollback, LOB, etc.)
- Response parsing helpers with full value deserialization for all 27+ CUBRID data types
- `ColumnMetaData` and `ResultInfo` dataclasses for structured query metadata

**Full Changelog**: https://github.com/cubrid-lab/pycubrid/compare/v0.1.0...v0.2.0
