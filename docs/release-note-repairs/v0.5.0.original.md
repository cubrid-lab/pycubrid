## v0.5.0 — SQLAlchemy Integration

### Added
- SQLAlchemy integration via `sqlalchemy-cubrid` v2.1.0 (`cubrid+pycubrid://` URL scheme)
- Updated README with SQLAlchemy usage examples

### Quick Start

```python
import pycubrid

conn = pycubrid.connect(host='localhost', port=33000, database='demodb', user='dba')
cursor = conn.cursor()
cursor.execute('SELECT * FROM db_class LIMIT 5')
rows = cursor.fetchall()
print(rows)
conn.close()
```

### With SQLAlchemy

```python
from sqlalchemy import create_engine

engine = create_engine("cubrid+pycubrid://dba@localhost:33000/demodb")
```
