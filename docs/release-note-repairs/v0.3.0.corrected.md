## v0.3.0 — Connection & Cursor

### Added
- PEP 249 `Connection` class with full CAS handshake lifecycle
- TCP socket management with partial-read handling
- `commit()`, `rollback()`, `close()`, `cursor()` methods
- `autocommit` property, `get_server_version()`, `get_last_insert_id()` helpers
- Context manager protocol (`with conn:` auto-close)
- PEP 249 `Cursor` class with full query execution (`execute`, `executemany`, `fetchone`, `fetchmany`, `fetchall`)
- Client-side parameter binding for all Python types
- `description` and `rowcount` attributes per PEP 249 spec

### Fixed
- Double-parse bug in `_send_and_receive()` — now correctly passes response body to packet parser
