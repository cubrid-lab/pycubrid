## pycubrid 1.0.0 — First Stable Release

### Stability Guarantee

The public API is frozen. Breaking changes will only occur in major version bumps (2.0+).

### Supported Environments

| Component | Versions |
|-----------|----------|
| Python | 3.10, 3.11, 3.12, 3.13 |
| CUBRID | 11.2, 11.4 |
| Protocol | CAS wire protocol v7 (CUBRID 10.0+) |

### Highlights

- **Pure Python**: No C extensions, no CCI dependency — implements CAS wire protocol directly
- **DB-API 2.0 compliant** (PEP 249): `apilevel="2.0"`, `threadsafety=1`, `paramstyle="qmark"`
- **PEP 561 typed**: Full type annotations with `py.typed` marker
- **99.88% test coverage**: 487 offline + 41 integration tests, CI-enforced ≥95%
- **Zero runtime dependencies**

### What's New in 1.0.0

- Resolved all mypy and pyright type safety errors
- Development Status: Beta → Production/Stable
