## v0.7.0 — Stabilization Release (path to 1.0)

This release defines the **1.0 support boundary** for pycubrid. After a soak period on PyPI, the next release will be 1.0 — a compatibility promise that the documented API surface is stable and production-ready.

### Added
- **Support Matrix** (`docs/SUPPORT_MATRIX.md`): Comprehensive compatibility document covering Python versions (3.10–3.13), CUBRID versions (10.2–11.4), PEP 249 compliance, data type mappings, driver features, and known limitations
- **Connection Pooling section** in `docs/CONNECTION.md`: Clarifies that pycubrid has no built-in connection pool and recommends SQLAlchemy's pool or external pooling libraries

### Fixed
- README documentation table: Removed incorrect "connection pool" reference from Connection guide description

### Changed
- Version bumped to 0.7.0

---

### 1.0 Support Boundary (Summary)

| Area | Status |
|---|---|
| PEP 249 DB-API 2.0 | ✅ Full compliance |
| Python 3.10–3.13 | ✅ |
| CUBRID 10.2–11.4 | ✅ |
| LOB, batch execute, CAS reconnect | ✅ |
| Collection types (SET/MULTISET/SEQUENCE) | ⚠️ Returned as raw bytes |
| JSON type | ❌ Not supported |
| Connection pooling | ❌ Use external pool |
| Async | ❌ Not supported |
