## What's New in v1.2.0

### Added
- **Async cursor parity** — sync and async cursors share identical security and feature logic (#76, #77)
- **Timezone datetime parsing** — `DATETIMETZ`/`TIMESTAMPTZ` wire format decoding (#78)
- **`cursor.nextset()`** for PEP 249 completeness (#79)
- **Configurable `fetch_size`** via `connect(fetch_size=N)` (#81)
- **Async `read_timeout`** and **dual-stack address fallback** (#82, #83)
- **Parameter binding hardening** — nan/inf rejection, DATETIMETZ literals, bytearray support (#74)
- **Native `Connection.ping()`** using CHECK_CAS (#70)
- **`errno`/`sqlstate` on `DatabaseError`** (#71)
- **JSON type decoding** with opt-in `json_deserializer` (#72)
- **Collection type decoding** — SET/MULTISET/SEQUENCE (#73)

### Security
- Hardened parameter binding: backslash escaping, null byte rejection, control character escaping (#74)

### Fixed
- Cursor registration dedup, `close()` best-effort exception handling (#76, #80)
- Test isolation and benchmark fixture fixes

### Breaking
- `_bind_parameters()` now only accepts `Sequence` (tuple/list) — `Mapping` (dict) parameter style removed
